# Konverter Migras

Folder ini berisi template konversi untuk sistem tujuan yang berbeda.

Saat ini tersedia:

- `to-postgres.sql` — template DDL + INSERT terkait tabel pinjaman/pendana/nasabah.
- `to-mongo.json` — contoh format dokumen untuk import ke MongoDB.
- `to-firebase.json` — contoh struktur dokumen untuk import ke Firebase/Realtime Database atau Firestore.
- `to-convex.md` — panduan migrasi ke project Convex lain.

Pilih satu sesuai sistem tujuan Anda. Jika Anda beri tahu Saya sistem tujuan yang Anda pilih, Saya bisa membuatkan konverter yang lebih spesifik dan terstruktur dari template ini.
